# 大乐透 / 双色球 数据分析模型

一个跨平台的彩票数据分析工具，支持**大乐透**和**双色球**两种彩种，提供历史数据查询、频率分析、统计图表、趋势预测、扫描验奖等功能。

## 功能模块

### 仪表盘
- 数据概览统计卡片（总期数、日期范围、最新开奖）
- 前区/后区号码频率柱状图（Chart.js）
- 最近50期和值趋势折线图

### 数据管理
- 历史开奖数据分页展示（倒序排列，最新在前）
- 一键刷新：从官方API获取最新真实开奖数据
- 数据本地缓存，支持离线查看

### 频率分析
- 前区/后区号码热力图
- 冷热号分析（Top N排名）
- 遗漏分析（当前遗漏、最大遗漏、平均遗漏）

### 统计分析
- 奇偶比分布分析
- 大小比分布分析
- 和值趋势分析（含均值、标准差）
- 区间分布统计
- 连号模式分析

### 趋势预测
- 加权随机预测（基于近期频率权重）
- 马尔可夫链预测（基于状态转移概率）
- 移动平均预测
- 综合预测（多模型融合）

### 扫描验奖（Android专属）
- 基于CameraX的摄像头实时扫描
- ML Kit中文OCR识别彩票号码
- 自动容错校正（O→0, I→1等常见OCR错误）
- 双色球6等奖级 / 大乐透9等奖级自动判定
- 显示中奖等级、命中号码、奖金金额
- 支持闪光灯控制，低光照环境可用
- 手动输入号码备选方案

### 数据导出
- CSV格式导出
- JSON格式导出
- Excel格式导出（含格式化）
- 综合分析报告导出

## 技术架构

```
├── app.py                  # Flask Web后端主程序
├── core/
│   ├── data_loader.py      # 数据加载与API对接
│   ├── frequency_analyzer.py # 频率分析引擎
│   ├── statistics.py       # 统计分析引擎
│   ├── trend_predictor.py  # 预测算法（加权/马尔可夫/移动平均）
│   └── exporter.py         # 数据导出（CSV/JSON/Excel）
├── web/
│   ├── templates/index.html # Web前端页面
│   └── static/
│       ├── css/style.css
│       └── js/
│           ├── app.js      # 前端核心逻辑
│           └── chart.min.js # Chart.js图表库
├── android/                # Android原生应用
│   └── app/src/main/java/com/lottery/analyzer/
│       ├── MainActivity.java       # WebView容器
│       └── ScannerActivity.java    # 摄像头扫描验奖
└── build_windows.spec      # PyInstaller打包配置
```

## Windows版 vs Android版 对比

| 特性 | Windows版 | Android版 |
|------|-----------|-----------|
| **运行方式** | 独立桌面程序（PyInstaller打包） | 原生APK安装包 |
| **界面技术** | Flask Web + 浏览器 | WebView + 原生Android |
| **扫描验奖** | 不支持 | 支持（CameraX + ML Kit OCR） |
| **闪光灯控制** | 不支持 | 支持 |
| **手动输入验奖** | 不支持 | 支持 |
| **数据分析** | 完整支持 | 完整支持 |
| **数据刷新** | 官方API在线获取 | 官方API在线获取 |
| **数据导出** | CSV / JSON / Excel / 报告 | CSV / JSON / Excel / 报告 |
| **预测模型** | 加权随机 / 马尔可夫 / 移动平均 / 综合 | 加权随机 / 马尔可夫 / 移动平均 / 综合 |
| **安装包大小** | ~16 MB | ~47 MB（含ML Kit模型） |
| **最低系统要求** | Windows 7+ | Android 8.0+ |
| **摄像头权限** | 不需要 | 需要 |

## 安装使用

### Windows版
下载 `大乐透数据分析模型.exe`，双击运行即可。程序会自动打开浏览器访问本地分析页面。

### Android版
下载 `大乐透数据分析模型_v1.0-release.apk`，在Android设备上安装后使用。首次使用扫描验奖功能时需授予相机权限。
